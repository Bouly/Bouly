# 🍔 BurgerVision AR

Application de réalité augmentée pour visualiser des burgers.

## 🚀 Déploiement

### Option 1: Netlify (Recommandé)
1. Allez sur [netlify.com](https://netlify.com)
2. Glissez-déposez le dossier complet du projet
3. Votre site sera en ligne avec HTTPS automatiquement !

### Option 2: GitHub Pages
1. Créez un repository GitHub
2. Uploadez tous les fichiers
3. Activez GitHub Pages dans Settings > Pages

## 📱 Utilisation
- Ouvrez l'application sur mobile avec HTTPS
- Autorisez l'accès à la caméra
- Cliquez sur un burger pour le voir en AR !

## 🛠 Technologies
- A-Frame (WebVR/WebXR)
- AR.js (Réalité Augmentée)
- HTML5/CSS3/JavaScript
