## 🎮 Guide d'interaction

### Mobile
- **1 doigt** : Déplacer la vue
- **2 doigts écartés** : Zoomer
- **2 doigts rotation** : Tourner l'objet
- **Double-tap** : Reset position

### Desktop
- **Souris** : Déplacer la vue
- **Flèches** : Tourner l'objet
- **↑/↓** : Zoomer/dézoomer
- **Espace** : Reset
